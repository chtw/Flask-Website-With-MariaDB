Flask Web Application

Project Description
This project is a web application developed using Python Flask, HTML and CSS, with a MariaDB database to store and retrieve data.

 Requirements
- Python 3
- Flask
- MariaDB 

Installation & Setup


Open the project folder in VS Code 

Create a Virtual Environment
Open the terminal and enter:

python -m venv venv
Activate the Virtual Environment

venv\Scripts\activate
```

Install Flask

pip install flask

Configure the Database
Ensure MariaDB/MySQL is running and configure the database connection details in app.py.

Make sure the required database and tables have been created.
Run the Application

Navigate to the folder containing `app.py` and run:

python app.py

View the Website
Open your web browser and navigate to:

http://127.0.0.1:5000
